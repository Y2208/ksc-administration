## 01. Gestión de Políticas de Seguridad
### Security Policy Management

**ES:** Diseño, implementación y mantenimiento de políticas de seguridad aplicadas a todos los endpoints de la organización a través de KSC 15.1.

**EN:** *Design, implementation, and maintenance of security policies applied to all organizational endpoints through KSC 15.1.*

**Responsabilidades / Responsibilities:**
- Creación y gestión de políticas de Kaspersky Endpoint Security
- Configuración de perfiles de seguridad por grupos de dispositivos
- Definición de reglas de control de aplicaciones y dispositivos
- Aplicación de políticas de control web
- Revisión y actualización trimestral de políticas

**Key skills demonstrated:**
`Policy Design` `Group Policy Management` `Endpoint Hardening` `Access Control`

## 02. Actualizaciones y Parches
### Updates & Patch Management

**ES:** Gestión centralizada de actualizaciones de bases de datos antivirus y parches de software en todos los endpoints desde KSC 15.1.

**EN:** *Centralized management of antivirus database updates and software patches across all endpoints from KSC 15.1.*

**Responsabilidades / Responsibilities:**
- Configuración y supervisión de tareas de actualización automática
- Diagnóstico y resolución de fallos en descarga de actualizaciones
- Gestión de servidor de distribución de actualizaciones
- Verificación de cobertura de actualización en todos los endpoints
- Resolución de errores: `File download error`, fallos de conectividad FTP/HTTP

**Key skills demonstrated:**
`Patch Management` `Update Distribution` `FTP Server Administration` `Troubleshooting`

## 04. Auditoría de Software
### Software Audit

**ES:** Auditorías periódicas de software instalado en endpoints para verificar cumplimiento de políticas, detectar software no autorizado y versiones desactualizadas.

**EN:** *Periodic software audits on endpoints to verify policy compliance, detect unauthorized software, and identify outdated versions.*

**Responsabilidades / Responsibilities:**
- Extracción de inventario de software desde KSC 15.1 y Goverlan
- Identificación de software no autorizado
- Detección de versiones desactualizadas con riesgo de seguridad
- Verificación de cumplimiento de políticas de uso de software
- Generación de reportes de hallazgos y recomendaciones

**Caso documentado / Documented case:**
> Auditoría de cumplimiento de software 2025 — [📄 Ver caso](../security-case-studies/audit-01-software/)

**Key skills demonstrated:**
`Software Asset Management` `Compliance Auditing` `Risk Assessment` `Goverlan`
